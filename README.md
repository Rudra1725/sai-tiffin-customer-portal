## 📌 About the Project

Sai Tiffin Services is a customer-facing website designed to bring a local home-style food business online. It makes it easier for customers to explore meal options, submit tiffin booking requests, and share suggestions directly through WhatsApp.

The project combines a modern interface with practical features to solve a real-world business problem.

## ✨ Features

- 🍱 **Tiffin Booking Portal** — Submit customer details, meal quantity, portion size, and delivery information.
- 📲 **WhatsApp Integration** — Send pre-filled booking requests directly to the service provider.
- 💡 **Customer Suggestions** — Submit dish recommendations and feedback through WhatsApp.
- ⭐ **Customer Reviews** — Display rotating review cards.
- 🎨 **Modern UI** — Dark theme, gradient accents, and glassmorphism-inspired styling.
- 🧊 **3D Card Effects** — Interactive tilt effects using Vanilla Tilt.js.
- 📱 **Responsive Styling** — CSS media queries adapt the layout to smaller screens.
- 📍 **Quick Contact** — Direct phone, WhatsApp, and Google Maps links.

## ⚙️ How It Works

1. Customers visit the website and explore the available services.
2. They fill in the tiffin booking form.
3. JavaScript formats their information into a pre-filled WhatsApp message.
4. WhatsApp opens so the customer can send the booking request.
5. Customers can use the suggestion form to share feedback or recommend dishes.

**Note:** The website currently uses WhatsApp for booking requests. It does not have an integrated backend database or online payment system.
